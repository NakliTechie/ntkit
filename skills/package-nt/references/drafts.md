## Phase 3 — Distribution drafts → `plan/launch-drafts.md`

- **The caption, first.** Open the file with one canonical caption: 1–3 sentences, postable as-is, in the product's own words. When the launch video ran, start from `plan/launch-caption.txt`. No "excited to share", no generic SaaS phrasing ("streamline your workflow"). Every channel draft below restates this caption's claim in that channel's voice and adds no claim the caption and README do not make.
- **Every draft is written in full plain sentences for a stranger.** Each sentence has a subject and a verb and states a fact with its name and number. Name each thing in full the first time. The repo's `ATTEST.md` section 4.4 lists the shapes to avoid: a denial of a view nobody stated ("It is not X. It is Y."), a claim of importance without the finding, verbless fragments for rhythm ("One file. No server."), a withheld name, a metaphor, and a closing line written to be quoted. Mark an opinion as the author's ("I find"). When a character limit forces compression, offer a longer post instead of compressing. Test each sentence: delete it, and cut it if no fact is lost.
- **X** — 2–3 hook variants (≤280 chars) and an optional thread, each pointing at the hero image.
- **LinkedIn** — one longer post.
- **Show HN** — `Show HN: <name> — <one-liner>` and a body: what it is, why you built it, how it works, what is honestly limited, an invite to feedback. No marketing voice.
- **Reddit** — subreddits from this project's actual domain, not generic ones, each with a tailored draft and a one-line note on that sub's self-promotion rules. No astroturf advice.
- **Optional** — a Product Hunt tagline and first comment, a dev.to or blog outline.
- **A where-to-post checklist**, sequenced.
