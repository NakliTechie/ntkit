## Writing back — how to record what you learn about me

This file is generated from `{{PREFS_DIR}}` by prefs-sync. Do not edit it: edits are moved to the
inbox at the next sync.

When you learn a lasting preference, correction or fact about me, my setup or the people I work with,
append one line to `{{PREFS_DIR}}/inbox.md`:

    - YYYY-MM-DD · <your agent name> · <the rule or fact, with its reason>

- Append only. Never rewrite or delete other lines.
- One fact per line. Include the reason ("because …") when there is one.
- A fact about one project goes to that project's own instructions or `plan/` folder instead.
- Inbox lines reach every agent at the next sync. A periodic fold moves them into the sections above.
